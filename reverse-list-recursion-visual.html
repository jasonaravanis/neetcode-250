The algorithm

def reverse(node):
    if node is None or node.next is None:
        return node              # base case: the last box
    new_head = reverse(node.next) # friend flips the rest
    node.next.next = node        # turn the box behind me around
    node.next = None           # I point at nothing (for now)
    return new_head            # relay the new front upward

The one idea that makes the return make sense:
reverse(node) promises to return the box that ends up at the front of its flipped stretch — never node itself.
 • reverse(4) → front of [4] = 4
 • reverse(3) → front of [4 → 3] = 4  (3 is at the back!)
 • reverse(2) → front of [4 → 3 → 2] = 4
 • reverse(1) → front of [4 → 3 → 2 → 1] = 4
That's why every frame returns the same value: 4. The deepest call (reverse(4)) discovers it, and every frame above just relays it with return new_head.
