Remove Element — Two-Pointer Visualizer

Step through the in-place two-pointer solution. Watch W (write) and R (read) move through the array.

← / → step  ·  space play/pause

Positions 0..W-1 = finalized keepers (green).
Positions W..R = the redundant gap (amber): every spot here was already examined — either its value was copied to the front when read saw it, or it equals val. Nothing unique lives there, so W is always safe to stomp on it.
Positions R+1..end = never touched yet (gray).

The algorithm

fun removeElement(nums: IntArray, val: Int): Int {
    var write = 0
    for (read in nums.indices) {
        if (nums[read] != val) {   // keeper?
            nums[write] = nums[read] // copy to front
            write++                  // advance the pile
        }                          // else → joins the redundant gap
    }
    return write                  // k = number of keepers
}
